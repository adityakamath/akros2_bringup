# akros2_bringup
ROS2 package to bringup the AKROS2 robot

* Configures and launches the [ldlidar](https://github.com/linorobot/ldlidar) node. It can be turned off using launch argument ```lidar:=false```. 
* Configures and launches the [realsense-ros](https://github.com/IntelRealSense/realsense-ros/releases) launch file for the T265 Tracking Camera. The T265 can be turned off using launch argument ```t265:=false```. 
* Configures and launches the [akros2_drive](https://github.com/adityakamath/akros2_drive) launch file. This launches the joystick controller nodes, the Twist related nodes and the micro-ROS agent. Drive can be turned off using launch argument ```drive:=false```.
* Launches [rosboard](https://github.com/adityakamath/rosboard) and/or [rosbridge_server](https://github.com/RobotWebTools/rosbridge_suite/tree/ros2/rosbridge_server/launch) based on launch arguments ```rosboard``` and ```rosbridge``` respectively. The ROSBridge Server node is used to connect to [Foxglove Studio](https://foxglove.dev/docs/studio/connection/rosbridge). Note that a for rosboard, personal fork is used, with the port number changed to 8000 instead of 8888, because 8888 is used by Jupyterlab in my environment. It also has some small (warning) fixes for Humble.
